# Tchap Desktop

This repo hosts the flatpak version of [Tchap-Desktop](https://github.com/tchapgouv/tchap-desktop)

Note that this is an **unofficial** redistribution.

## Installing

```bash
flatpak install flathub fr.gouv.Tchap
```

## Issue reporting

**Please only report issues in this repo that are specific to the flatpak version.**

Issues that can be replicated in a stable release should be reported in the [upstream repo](https://github.com/tchapgouv/tchap-desktop/issues)
Make sure, that the reported issue is **not** flatpak-related.
